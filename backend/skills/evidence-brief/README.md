# Evidence Brief — skill folder README

> **Read this first.** This folder is NOT a full agent skill any more. It is the
> **rendering contract** for the evidence artifact: the markup, class vocabulary
> and component set the model must emit. The *content* of a brief — the
> analysis, the findings, the grounding and honesty rules — lives in the calling
> prompt (`app/prompts.py`), not here.

---

## 1. The split (why this folder is small)

The evidence brief used to be generated by handing the model a full method
("read each signal for its one finding, converge ≥2 independent signals, find
the wedge, run the honesty pass…") *plus* five worked example briefs, and
letting the skill own both what to say and how it looks. That put the analysis
in a vendored markdown file, one step removed from the code that knows what data
was actually retrieved.

It is now split at the seam:

| Layer | Owns | Lives in |
|---|---|---|
| **Prompt** | WHAT the brief says — reading the trail, convergence, the wedge, chart choice per finding, quote rules, degradation, the honesty pass, voice and title | `backend/app/prompts.py` (`EVIDENCE_KG_SYSTEM` / `EVIDENCE_KG_USER_TEMPLATE`) |
| **This skill** | HOW it is rendered — document shape, empty `<style>`, class vocabulary, component table, chart markup, the no-script boundary | `SKILL.md` + `references/component-reference.html` |
| **Server** | The stylesheet, applied after generation | `assets/evidence.css` via `app.html_style.inject_canonical_css` |
| **Server** | Normalising the model's output to the render contract | `app.evidence_html.normalize_evidence_html` |

`SKILL.md` states this explicitly: where the prompt and the skill appear to
disagree about *content*, the prompt wins; the skill is authoritative only for
markup.

## 2. What the model produces

ONE self-contained HTML document, 1–3 pages:

```
<meta charset="utf-8">
<style></style>              <- EMPTY; the server splices assets/evidence.css in
<div class="wrap">…</div>    <- the brief
```

Charts are hand-authored inline `<svg>`. There is never a `<script>`: the
document renders in an iframe with `sandbox="allow-same-origin"` and **no**
`allow-scripts`, so anything requiring JavaScript renders as nothing. That is a
security boundary — see `~/sprntly-brain/architecture/html-surface-sandbox.md`.

## 3. Folder contents

```
evidence-brief/
|-- SKILL.md                              # the rendering contract (injected as METHOD)
|-- README.md                             # this guide (never injected)
|-- assets/
|   `-- evidence.css                      # canonical stylesheet, injected SERVER-side
`-- references/
    `-- component-reference.html          # every component + chart form, canonical
                                          # markup, placeholder words (injected)
```

`references/*` is folded into the model's prompt by
`graph.gateway._build_method_prefix`; `assets/*` deliberately is not — the
server applies it to the finished document.

### Why one reference and not five

The five worked briefs that used to live here (Lyra, Northwind, Trailhead,
Cartwheel, Aperture — 601 lines, ~14k prompt tokens) taught two things at once:
markup *and* how to construct an argument. The second half is now the prompt's
job, and the examples actively fought the contract — each one carried its own
full `<style>` block with colours and classes (`--warn`, `.kicker.w`) that the
canonical stylesheet does not define, while `SKILL.md` told the model to emit an
empty `<style>`.

`component-reference.html` is what is left when you keep only the form: every
component and chart shape, in the canonical vocabulary, with an empty `<style>`
and deliberately meaningless words, so there is nothing in it to imitate except
the markup.

## 4. Where it is bound

Statically, by name, from three call sites — never routed from chat:

- `app/evidence_kg.py::build_evidence_kg` — KG-grounded insight evidence
- `app/evidence_kg.py::_run_sync_task` — chat-task evidence
- `app/evidence_runner.py::_run_sync` — corpus fallback

All three pass `skill="evidence-brief"` to `graph.gateway.llm_call`, which folds
`SKILL.md` + `references/*` onto the cacheable prefix and records the skill's
`content_hash` in `prompt_version`.
